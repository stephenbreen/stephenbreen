### Hi, I'm Stephen 👋

I write software in Cork, Ireland: Azure platforms and telematics pipelines
by day, tools for D&D tables and terminals the rest of the time. Most of it
started at a real game night, or because something in my terminal annoyed me.

**At the table**

- [**Cork D&D Club**](https://corkdnd.com): where all of it gets stress-tested. Come play if you're local.

**At the desk and in the terminal**

- [**pgWhy**](https://github.com/stephenbreen/pgWhy): a desktop Postgres client for people who miss SSMS (Rust + Tauri).
- [**git-tagger**](https://github.com/stephenbreen/git-tagger): see which commits shipped between two git tags (Rust TUI).
- [**memo**](https://github.com/stephenbreen/memo): flashcards for the shell commands you keep re-googling (Python).
- [**ogham-note**](https://github.com/stephenbreen/ogham-note): a native macOS Markdown editor with a real Vim engine (Swift).
